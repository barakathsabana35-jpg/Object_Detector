🔍 AI Object Detection

A simple AI-powered object detection web application built using **Python, Streamlit, and YOLO11**. Users can upload an image, and the YOLO model detects and identifies the objects present in the image.

🛠️ Technologies Used

* Python
* Streamlit
* Ultralytics YOLO11
* PyTorch
* Pillow

✨ Features

* Upload JPG, JPEG, or PNG images
* Detect multiple objects in an image
* Display the uploaded image
* Show identified object names
* Simple and interactive Streamlit interface

🎯 Learning Outcome

This project demonstrates how to integrate a pretrained **YOLO object detection model** with a Python-based Streamlit web application for real-time image analysis.
